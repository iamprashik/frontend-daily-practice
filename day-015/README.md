# Day 015 - Generate a Random Number

## What I practiced

Today I practiced generating random numbers in JavaScript using `Math.random()`.

## What I learned

- `Math.random()` generates a random decimal number between `0` and `1`.
- The value can be multiplied to create a larger range.
- `Math.floor()` can be used to turn the result into a whole number.
- Combining `Math.random()` and `Math.floor()` is useful for generating random integers.

## Example

```javascript
const randomNumber = Math.random();

console.log(randomNumber);
```
