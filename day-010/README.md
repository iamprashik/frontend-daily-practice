# Day 010 - String Uppercase and Lowercase Methods

## What I practiced

Today I practiced changing the capitalization of strings in JavaScript using `toUpperCase()` and `toLowerCase()`.

## What I learned

- `toUpperCase()` converts all characters in a string to uppercase.
- `toLowerCase()` converts all characters in a string to lowercase.
- These methods do not change the original string.
- The converted value can be stored in a new variable.
- These methods are useful when comparing or formatting text.

## Example

```javascript
const language = "JavaScript";

console.log(language.toUpperCase());
console.log(language.toLowerCase());
