# Day 004 - `typeof` and Type Checking

## What I practiced

Today I practiced checking the data type of values in JavaScript using the `typeof` operator.

## What I learned

- `typeof` tells us the type of a JavaScript value.
- Strings return `"string"`.
- Numbers return `"number"`.
- Booleans return `"boolean"`.
- Undefined values return `"undefined"`.
- `typeof` can be used in conditions to check a value before using it.

## Example

```javascript
const name = "Prashik";
const age = 23;
const isLearning = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isLearning);
