Day 048 - Looping Through Arrays

What I practiced

* Using a for loop with an array
* Using a for...of loop
* Accessing array elements with indexes
* Iterating through multiple values

What I learned

* A for loop can use an index to access each array element.
* i++ increases the index by one.
* A for...of loop gives you each array element directly.
* Both loops can process every item without repeating code manually.

Example

const fruits = ["Apple", "Banana", "Orange"];
for (const fruit of fruits) {
    console.log(fruit);
}

Output:

Apple
Banana
Orange
