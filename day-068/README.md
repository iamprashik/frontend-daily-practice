Day 068 - Create and Access an Object

What I practiced

* Creating JavaScript objects.
* Storing information using key-value pairs.
* Accessing properties using dot notation.
* Accessing properties using bracket notation.
* Using variables with bracket notation.

What I learned

* Objects store information using key-value pairs.
* Each key represents a property.
* Dot notation accesses properties directly.
* Bracket notation can use a string or variable to access a property.
* Accessing a property that doesn’t exist returns undefined.

Example

const student = {
    name: "Alex",
    age: 22,
    program: "Computer Science",
    grade: 85
};
console.log(student.name); 
console.log(student["age"]);
