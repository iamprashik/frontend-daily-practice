# Day 002 - Variables with `const` and `let`

## What I practiced

Today I practiced creating variables in JavaScript using `const` and `let`.

## What I learned

- Use `const` for values that should not be reassigned.
- Use `let` for values that may change.
- Variable names should be clear and meaningful.

## Example

```javascript
const name = "Prashik";
let completedDays = 1;

completedDays = 2;
