# Day 014 - Math.round(), Math.floor(), and Math.ceil()

## What I practiced

Today I practiced rounding numbers in JavaScript using `Math.round()`, `Math.floor()`, and `Math.ceil()`.

## What I learned

- `Math.round()` rounds a number to the nearest whole number.
- `Math.floor()` always rounds a number down.
- `Math.ceil()` always rounds a number up.
- These methods are useful when working with calculations involving decimal numbers.

## Example

```javascript
const number = 4.7;

console.log(Math.round(number));
console.log(Math.floor(number));
console.log(Math.ceil(number));
```
