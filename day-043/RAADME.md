Day 043 - Character Counter

What I practiced

* Counting characters with .length
* Creating functions with parameters
* Returning values from functions
* Calling a function with different strings

What I learned

* The .length property tells us how many characters a string contains.
* Spaces and punctuation count as characters.
* A reusable function can count characters in different strings.

Example

function countCharacters(text) {
    return text.length;
}
console.log(countCharacters("Hello"));

Output:

5
