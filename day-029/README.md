# Day 029 - Return Values

## What I practiced

Using `return` to send a value back from a function.

## What I learned

* `return` sends a value back from a function.
* A returned value can be stored in a variable.
* A returned value can be used in calculations.
* `return` also stops the function from running further.

## Example

```js
function add(a, b) {
    return a + b;
}

const result = add(10, 5);

console.log("Result:", result);
```

## Expected output

```text
Result: 15
```

node day-029/script.js
