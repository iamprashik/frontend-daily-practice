# Day 027 - Function Declarations

## What I practiced

Creating and calling functions in JavaScript.

## What I learned

* A function is a reusable block of code.
* A function is created using the `function` keyword.
* The code inside a function runs when the function is called.
* Functions help avoid repeating the same code.
* A function can be called multiple times.

## Example

```js
function greet() {
    console.log("Hello, Prashik!");
}

greet();
```

## Expected output

```text
Hello, Prashik!
```
