# Day 008 - Template Literals

## What I practiced

Today I practiced using template literals in JavaScript to create strings and include variables inside them.

## What I learned

- Template literals use backticks `` ` ` `` instead of quotes.
- `${}` can be used to insert variables into a string.
- Expressions and calculations can also be placed inside `${}`.
- Template literals make it easier to create readable strings.
- Template literals can be used to create multi-line strings.

## Example

```javascript
const name = "Prashik";
const age = 23;

console.log(`My name is ${name} and I am ${age} years old.`);
```
