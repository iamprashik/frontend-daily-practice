# Day 020 - Ternary Operator

## What I practiced

Today I practiced using the ternary operator in JavaScript as a shorter way to write simple `if/else` statements.

## What I learned

- The ternary operator uses the `?` and `:` symbols.
- The condition comes before `?`.
- The value after `?` is used when the condition is true.
- The value after `:` is used when the condition is false.
- Ternary operators are useful for simple conditions.

## Example

```javascript
const age = 20;

const result = age >= 18 ? "Adult" : "Minor";

console.log(result);
```
