# Day 006 - Comparison Operators

## What I practiced

Today I practiced using comparison operators in JavaScript to compare values.

## What I learned

- `==` checks if two values are equal after type conversion.
- `===` checks if two values and their types are equal.
- `!=` checks if two values are not equal.
- `!==` checks if two values or their types are not equal.
- `>` checks if the left value is greater.
- `<` checks if the left value is smaller.
- `>=` checks if the left value is greater than or equal.
- `<=` checks if the left value is smaller than or equal.
- Comparison operators return either `true` or `false`.

## Example

```javascript
const age = 23;

console.log(age > 18);
console.log(age < 18);
console.log(age === 23);
console.log(age !== 20);
```
