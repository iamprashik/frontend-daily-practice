# Day 005 - Arithmetic Operators

## What I practiced

Today I practiced using arithmetic operators in JavaScript to perform basic mathematical calculations.

## What I learned

- `+` adds two values.
- `-` subtracts one value from another.
- `*` multiplies two values.
- `/` divides one value by another.
- `%` returns the remainder after division.
- `**` raises a number to a power.

## Example

```javascript
const a = 10;
const b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);
```
