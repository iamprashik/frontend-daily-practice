# Day 022 - for Loop Counting

## What I practiced

Today I practiced using a `for` loop in JavaScript to repeat code and count through numbers.

## What I learned

- A `for` loop repeats code while a condition is true.
- The initialization runs once at the beginning.
- The condition is checked before each iteration.
- The increment updates the counter after each iteration.
- A `for` loop is useful when I know how many times I want to repeat something.

## Example

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```
